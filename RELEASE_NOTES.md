# Thesis supplementary material v1.0

Initial supplementary package for Kyriakos Christodoulides's thesis, *Geometry-Aware Multi-RIS Index Modulation for mmWave Communications: Modeling, Optimization, and a 28 GHz Experimental Proof of Concept*.

Includes:

- Saved summary CSVs for the independent-panel detection and shared-ray configuration-selection comparisons.
- Column definitions, method descriptions, and ensemble interpretation.
- A plotting helper and example PDF/PNG figures.
- Citation metadata and checksums for the CSV files.

The package supports reproduction of the plotted summaries. It does not include complete per-realization simulation data, the complete original simulation implementation, or raw experimental measurements.
